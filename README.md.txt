Customer Churn Detection

This project predicts whether a customer will churn (leave) or not using machine learning.

Problem Statement
Customer churn is a major problem for businesses. This model helps identify customers who are likely to leave.

Techniques Used
- Logistic Regression
- Data Preprocessing
- Feature Scaling

Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

 Output
The model predicts customer churn with good accuracy.
